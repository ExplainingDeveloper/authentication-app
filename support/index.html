계정 삭제 안내

[여기에 앱 이름 입력](개발자: [여기에 개발자/회사명 입력])은 사용자가 원하실 때 언제든지 계정과 관련 데이터를 삭제하실 수 있도록 안내해 드리고 있습니다. [여기에 앱 이름 입력]은 구글 로그인과 애플 로그인(OAuth)을 통해 회원가입 및 로그인을 제공하므로, 계정 삭제 역시 가입에 사용하신 구글 또는 애플 계정을 기준으로 처리됩니다. 아래 방법 중 편하신 방법을 선택해 주세요.

방법 1. 앱 내에서 직접 삭제하기

가장 빠른 방법입니다. 앱에 로그인하신 상태에서 앱 내 설정 > 계정 삭제(회원탈퇴) 경로로 이동하신 뒤 안내에 따라 진행해 주세요. 보안을 위해 삭제 직전에 구글 또는 애플 계정으로 다시 한 번 로그인(재인증)을 요청드릴 수 있습니다. 삭제가 완료되면 계정은 즉시 사라지며, 되돌릴 수 없습니다.

방법 2. 이메일로 삭제 요청하기

앱에 로그인할 수 없거나 직접 삭제가 어려우신 경우, 아래와 같이 이메일로 요청해 주시면 [여기에 개발자/회사명 입력]에서 확인 후 처리해 드립니다.

  • 받는 사람: [여기에 문의 이메일 입력]
  • 제목: 계정 삭제 요청
  • 본문: 가입 시 사용하신 이메일 주소(구글 또는 애플 계정 이메일)를 반드시 함께 적어주세요. 본인 확인이 되지 않으면 요청을 처리해 드릴 수 없습니다.

애플 로그인 사용 시 “나의 이메일 주소 가리기”를 선택하셨다면 @privaterelay.appleid.com으로 끝나는 비공개 이메일 주소가 발급됩니다. 이 경우 해당 비공개 주소를 적어주시거나, 그 주소로 메일을 보내주시면 본인 확인이 가능합니다.

이메일로 요청해 주신 경우, 접수 후 영업일 기준 3일 이내에 처리 결과를 회신해 드립니다.

삭제되는 데이터와 보관되는 데이터

계정 삭제 요청이 접수되면 이름, 이메일 주소, 프로필 사진 등 회원님을 식별할 수 있는 개인 데이터와 앱 이용 중 생성된 데이터는 즉시 삭제되며 복구할 수 없습니다. 다만 부정 이용 방지 및 관련 법령상의 의무를 이행하기 위해 일부 데이터는 [여기에 보관 기간, 예: 30일] 동안 분리 보관된 뒤 완전히 파기됩니다.

구분 항목 처리 방식
즉시 삭제 이름, 이메일 주소, 프로필 사진, 로그인 계정 연동 정보, 앱 내 이용 데이터 계정 삭제 처리와 동시에 삭제되며 복구 불가
한시 보관 후 파기 부정 이용 방지 및 법령 준수를 위한 최소한의 기록(접속 로그, 처리 이력 등) [여기에 보관 기간, 예: 30일] 동안 별도 분리 보관 후 자동 파기

계정을 삭제하시면 [여기에 앱 이름 입력]과 구글·애플 계정의 연동도 함께 해제됩니다. 다시 이용하고 싶으실 때는 언제든지 처음처럼 새로 가입하실 수 있으며, 이 경우 이전에 사용하시던 데이터는 복구되지 않는 점 양해 부탁드립니다.
